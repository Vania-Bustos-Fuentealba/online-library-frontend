# Aplicación React vigente

Esta carpeta contiene la aplicación que se desarrolla en feature/react-tienda.

- Instalación: `npm ci`.
- Desarrollo: `npm run dev`.
- Compilación: `npm run build`.
- Lint: `npm run lint`.
- Pruebas y cobertura: `npm run coverage`.

Lee el [README del repositorio](../README.md) y el [documento de administración](../ADMINISTRACION.md) para configuración, rutas, requisitos y límites. El login utiliza Auth por el Gateway y el CRUD administrativo requiere la versión del backend incluida en esta revisión. No utiliza cuentas simuladas.
