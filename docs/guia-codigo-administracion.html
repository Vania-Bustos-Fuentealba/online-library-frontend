Guía del código administrativo

Online Library · revisión del 23 de noviembre de 2026.

Esta guía contiene el código de administración, sesión y contratos del backend revisados. Cada fila conserva su número de línea y una nota de lectura. Los comentarios insertados en el repositorio explican las decisiones específicas; las notas laterales ayudan a reconocer la sintaxis.

Recorrido para estudiar

Empieza por App.jsx → AdminLayout → api.js → el formulario de usuarios. Después sigue la misma petición en Gateway → AuthStateVerifier → SecurityConfig → AdminAccountController → AdminAccountService. Auth guarda cuentas y user-service guarda perfiles: sus identificadores son distintos.

Una prueba con fetch simulado comprueba React. Una prueba de seguridad comprueba Spring. Una prueba con Docker y MySQL comprueba comunicación y persistencia reales. Ninguna de estas capas reemplaza a las otras.
